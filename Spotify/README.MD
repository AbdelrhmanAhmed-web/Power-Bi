# 🎵 Spotify Listening Habits Analysis Dashboard
## 🚀 Project Overview
This Power BI dashboard provides a deep dive into personal Spotify listening habits. It transforms raw streaming data into actionable insights, focusing on artist loyalty, track frequency, and seasonal listening patterns.
![Project Overview](/Spotify/Spotify_Overview.png)
## 🧠 Key Features & Technical Highlights
* **Dynamic Scatter Plot with Parameters:** * Implemented a custom **Dynamic Highlighting** system using Numeric Parameters.
    * Users can set thresholds for `Listening Time` and `Track Frequency`. 
    * **DAX Logic:** Points automatically change color (Spotify Green vs. Gray) based on user-defined inputs to isolate "Obsessed" tracks from casual listens.
* **Advanced Tooltips:**
    * Customized **Report Page Tooltips** that display detailed track metadata (Artist, Song Name, Play Count) upon hovering, providing context without cluttering the main view.
* **Time Intelligence:**
    * Analysis of listening patterns across months and years (YoY Growth metrics).
* **Custom Brand Theme:**
    * The UI is fully aligned with Spotify’s dark-mode aesthetic for an immersive user experience.

## 🛠️ Tech Stack
* **Tool:** Power BI Desktop
* **Language:** DAX (Data Analysis Expressions)
* **Data Source:** Spotify Personal Data Export (CSV)

## 📊 Visuals Included
1.  **Executive Summary:** KPIs for total minutes played, top artists, and unique tracks.
2.  **Listening Patterns:** A sophisticated scatter plot to identify "High Frequency" vs. "High Duration" songs.
3.  **Artist Deep-Dive:** Analysis of top-performing artists and album distribution.

## 💡 Insights
Through this dashboard, I identified my "Comfort Artists" (high frequency over long periods) versus "Viral Hits" (high frequency in a short burst). It also highlights the impact of specific seasons on music genre preferences.
